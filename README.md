# python-number-guessing-game
Pythonで作成した、簡単な桁ごとの数字と位置を推理するゲームです。

## 💡 ルールと仕様
- **H（Hit）**: 数字も位置（桁）も合っている数
- **B（Blow）**: 数字は合っているが、位置（桁）が違う数
- プレイヤーが4桁の数字を入力すると、毎回「X H - Y B」の形式でヒントが表示されます。
- 例：正解が「3705」で、入力が「1738」の場合 ➡️ `1H - 1B`

## 🛠️ 使用技術
- **言語**: Python 3.x
- **標準ライブラリ**: `random` (ランダムな数字の生成用)

## ✨ 工夫した点・こだわったポイント（技術的アピール）
1. **厳密な入力チェック（バリデーション）の実装**
   - プレイヤーが「4桁以外の数字」「数字以外の文字」「重複のある数字（例: 1122）」を入力した際に、エラーで強制終了せず、再入力を促す例外処理・条件分岐を徹底しました。
2. **HitとBlowの判定判定ロジックの効率化**
   - リストのインデックス（位置）と要素（数字）を同時に比較するため、Pythonの `enumerate()` 関数を活用し、シンプルで読みやすい判定ロジックを構築しました。
3. **ゲーム性の担保（重複なしのランダム生成）**
   - 正解となる4桁の数字に重複が出ないよう、`random.sample()` を使用して「0〜9のユニークな3つの数字」を確実に生成する仕様にしました。
